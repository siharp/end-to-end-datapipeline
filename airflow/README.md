# 🚀 Apache Airflow Setup Guide

This section provides step-by-step instructions to run Apache Airflow as the primary orchestrator for this Modern Data Stack pipeline using Docker.

## 1. Requirements
Before starting, ensure your system meets the following minimum specifications:
- **Docker Desktop**: Version 20.10.0 or later.
- **Docker Compose**: Version 1.29.0 or later.
- **System Resources**: Minimum 4GB RAM allocated to Docker (8GB recommended to run the full stack).

## 2. Running with Docker
Execute the following command in your terminal from the project's root directory:
```bash
docker-compose up --build -d
```

## 3. Accessing the Dashboard
URL: http://localhost:8080
